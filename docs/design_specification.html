🚀 1. Executive Summary & Product Vision

"Are You a Prompting Wizard?" (Repository: aosterloh/prompt-wizard) is a real-time, interactive multi-player party game web application designed for live audience participation. Players connect using their smartphones by scanning a QR code on the main stage display.

Each round presents a hidden target benchmark image (`target_1.png` .. `target_15.png`). Players enter custom prompts attempting to reverse-engineer and recreate the benchmark image using Google's Gemini AI. The game automatically evaluates prompt similarity, synthesizes player artworks, and presents anonymized voting choices before revealing the winner with Gemini AI Judge rationale and confetti celebrations!

⚙️ 4. Key Subsystem Specifications

📷 Infallible Client-Side QR Code Engine (`public/js/qrcode.min.js`)

To prevent reliance on third-party network APIs (`api.qrserver.com`) that can be blocked by extensions or firewalls, the host uses a standalone, zero-dependency HTML5 Canvas QR generator.

  • Error Correction Level: Level H (30% error recovery capacity).
  • Latency: 0ms instant synchronous base64 Data URI generation.
  • URL Resolution: Derives player join URL synchronously from window.location.origin replacing /host with /player?room=WIZARD.

🎵 Web Audio API Countdown Synthesizer

An embedded synthesizer built directly with the browser's native AudioContext. Triggers escalating audio countdown beeps during the final 10 seconds of the PROMPTING phase:

  • Seconds 10–6: 440 Hz (Standard A tone)
  • Seconds 5–4: 660 Hz (Medium alert pitch)
  • Seconds 3–1: 880 Hz (High urgency pitch)

🤖 Gemini AI Judge Engine

When votes end in a tie or host triggers the AI Judge, Socket.IO emits host:askAiJudge. The server queries Gemini AI to evaluate the similarity between player prompt texts and the benchmark image, producing:

  • Winning Choice Letter: Selected artwork (e.g. choice `B`).
  • AI Rationale Text: Explainer text detailing why the prompt best captured color composition, subject detail, and stylistic fidelity.

📡 5. Network Protocols & Socket.IO Events

Event Name Direction Payload Data Function
host:register Client ➔ Server { roomCode: "WIZARD" } Registers host socket connection to room channel.
player:join Client ➔ Server { roomCode, playerName } Joins player to active game session.
player:submitPrompt Client ➔ Server { roomCode, promptText } Submits player prompt for current benchmark image.
host:startGame Client ➔ Server { roomCode } Transitions game state from LOBBY to PROMPTING.
room:stateUpdate Server ➔ Client { gameState, players, currentTargetImage, ... } Broadcasts complete room state snapshot to sync UI.
room:timerUpdate Server ➔ Client { timer: 45 } Broadcasts 1-second countdown ticks to host & players.

🌍 6. Deployment & Environment Setup

# 1. Clone Official Repository
git clone https://github.com/aosterloh/prompt-wizard.git
cd prompt-wizard

# 2. Local Environment Setup
cp .env.example .env
# Edit .env and set GEMINI_API_KEY

# 3. Deploy to Google Cloud Run
gcloud run deploy art-showdown \
  --source . \
  --region europe-west3 \
  --allow-unauthenticated \
  --project aosterloh-cs-muc \
  --set-env-vars "GEMINI_API_KEY=YOUR_GEMINI_KEY"
